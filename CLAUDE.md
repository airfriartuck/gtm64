# GTM64 project instructions

- At the start of every session, before doing any work, read and follow `CLAUDE.local.md` from the repository root if it exists.
- If it is absent in the current Git worktree, locate the primary checkout with `git worktree list --porcelain` and read its `CLAUDE.local.md` if present.
- Keep personal instructions in that local file; do not duplicate them into shared instructions or commit them.
